# 3.117.2 (2026-10-13)

## Fixed

- A source that is not a book now says what its reference is (PubMed id, DailyMed set id, gene, GtoPdb target...) instead of a page number such as "p. 7827213", and links to the record when it has a public page, for example a study's Europe PMC entry (a267780)
  fr: Une source qui n'est pas un livre indique désormais la nature de sa référence (identifiant PubMed, set id DailyMed, gène, cible GtoPdb...) au lieu d'un numéro de page comme « p. 7827213 », et renvoie vers la fiche quand elle a une page publique, par exemple l'entrée Europe PMC d'une étude (a267780)
