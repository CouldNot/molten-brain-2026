# 3.93.2 (2026-10-10)

## Improved

- Every drug's Enzymes section now says out loud what its list is: the routes some source here happens to name, never the full set. Each row was already sourced individually, but the list never was, so a missing isoform read like a claim that the drug avoids that route instead of a hole in the sources. The note also says where the hole propagates: the drug-to-drug interaction rows are derived from that same list, so an unnamed shared route is an interaction nothing draws (the shape of the clomipramine/CYP2C19 gap closed in 3.93.1). Written once for the section rather than copied onto 240 drugs, and deliberately unsourced, since the claim is about this dataset's coverage and no corpus could be cited for it.
