# 3.103.0 (2026-10-12)

## Added

- Data from the Guide to Pharmacology now carries the citation that database asks for (its 2026 Nucleic Acids Research paper, the Concise Guide to PHARMACOLOGY chapter for target data, and its CC BY-SA 4.0 licence), under each of its source pills and in the Sources popup. (6e05f72)
  fr: Les données du Guide to Pharmacology portent désormais la citation que cette base demande (son article 2026 dans Nucleic Acids Research, le chapitre du Concise Guide to PHARMACOLOGY pour les données sur les cibles, et sa licence CC BY-SA 4.0), sous chacune de ses pastilles de source et dans la fenêtre Sources. (6e05f72)

## Improved

- The Guide to Pharmacology now requires an API key for its web services; the tools that download its tissue-distribution and target-classification data send one, so those sources can be refreshed again. (cef4a23)
  fr: Le Guide to Pharmacology exige désormais une clé d'API pour ses services web ; les outils qui téléchargent ses données de distribution tissulaire et de classification des cibles en envoient une, ces sources peuvent donc de nouveau être rafraîchies. (cef4a23)
