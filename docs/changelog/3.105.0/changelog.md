# 3.105.0 (2026-10-12)

## Improved

- A receptor or target panel now also lists a prodrug that acts there through a modeled metabolite drug (lisdexamfetamine on the dopamine transporter, via dextroamphetamine), without counting it twice. (ad9a23f)
  fr: Une fiche de récepteur ou de cible liste désormais aussi un promédicament qui y agit par un métabolite modélisé comme médicament (la lisdexamfétamine sur le transporteur de la dopamine, via la dextroamphétamine), sans le compter deux fois. (ad9a23f)
