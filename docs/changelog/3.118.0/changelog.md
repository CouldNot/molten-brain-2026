# 3.118.0 (2026-10-13)

## Improved

- A drug's "Acts on" section is now called "Direct action on receptors", and for a drug with active metabolites it opens with a warning naming them, since their own actions are not in that list, with a link that jumps to the Active metabolites section (3714e06)
  fr: La section « Agit sur » d'un médicament s'appelle désormais « Action directe sur les récepteurs » et, pour une substance qui a des métabolites actifs, elle commence par un avertissement qui les nomme, puisque leurs propres actions ne figurent pas dans cette liste, avec un lien vers la section Métabolites actifs (3714e06)
