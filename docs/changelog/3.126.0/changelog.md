# 3.126.0 (2026-10-15)

## Added
- A drug panel now has a "Brain entry" section: how fat-soluble the drug is (XLogP3) and how polar (polar surface area), computed by PubChem, plus whether it crosses the blood-brain barrier (BBB+ or BBB-, with logBB when measured) from the B3DB dataset, each with a tooltip on how to read it (43ac690, 7546ebb, 4c93863, cd0b4b2)
  fr: Le panneau d'un médicament a désormais une section « Entrée dans le cerveau » : sa liposolubilité (XLogP3) et sa polarité (surface polaire), calculées par PubChem, ainsi que son passage de la barrière hémato-encéphalique (BHE+ ou BHE-, avec le logBB quand il est mesuré) d'après le jeu de données B3DB, chacune avec une infobulle expliquant comment la lire (43ac690, 7546ebb, 4c93863, cd0b4b2)
