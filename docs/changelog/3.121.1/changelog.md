# 3.121.1 (2026-10-14)

## Improved
- A mistyped /api address now shows the list of every page with its id instead of a bare error, each kind has its own list (e.g. /api/drug/), and the .md ending is optional
  fr: Une adresse /api erronée affiche désormais la liste de toutes les pages avec leur identifiant au lieu d'une simple erreur, chaque type a sa propre liste (par ex. /api/drug/), et l'extension .md est facultative
